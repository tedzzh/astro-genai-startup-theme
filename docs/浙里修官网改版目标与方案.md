# 浙里修（zhelifix）官网改版目标与方案

## 一、目标

- **品牌**：浙里修 zhelifix（官网域名 zhelifix.com）
- **定位**：芯片级维修工作室
- **业务**：
  - 计算机芯片级维修
  - 工控设备维修
  - 无人机维修
  - 软件脚本开发
  - 网络设计维护
  - 特斯拉相关（进修中）
- **呈现**：全中文官网，无明显英文；图片使用占位符便于后续替换；保留现有基础框架，可扩展新页面。

## 二、保留的页面与框架

| 页面 | 说明 |
|------|------|
| 首页 `/` | Hero + 服务项目(Features) + 客户评价(Testimonials) + 价格/咨询(Pricing) + 常见问题(FAQ) |
| 关于我们 `/about` | 工作室介绍、使命愿景、资质 |
| 联系我们 `/contact` | 表单 + 联系信息 |
| 隐私/条款 | `/privacy`、`/terms` 保留，文案改为中文 |

## 三、内容与文案方向

- **首页**
  - **Hero**：主标题突出「芯片级维修」「专业、透明、可靠」；副标题与按钮全中文。
  - **服务项目**：六块对应——芯片级维修、工控设备维修、无人机维修、脚本开发、网络设计维护、特斯拉（进修中）；每块配图标 + 短文案 + 占位图（可选）。
  - **客户评价**：中文称呼、身份、评价内容；头像使用占位图路径，便于替换。
  - **价格/咨询**：维修服务档位（如检测费、标准维修、企业合作等），全部中文。
  - **常见问题**：维修流程、保修、报价方式、周期等，全中文问答。

- **关于我们**：工作室故事、使命愿景、团队/资质；图片用占位符。

- **联系我们**：表单标签与占位符全中文；邮箱/电话/地址用占位符，方便你替换。

## 四、图片占位规范

- 所有图片统一使用 `public/images/` 下路径，便于替换。
- 占位约定：
  - `images/logo.svg`：站点头部 Logo（可替换为你的 Logo）
  - `images/hero-placeholder.jpg`：首页主视觉（可选）
  - `images/service-*.jpg`：各服务项配图（如 service-chip.jpg）
  - `images/avatar-*.jpg`：客户评价头像
  - `images/about-*.jpg`：关于我们配图
- 若文件暂无，先用占位路径；你只需将真实图片放入对应路径即可替换。

## 五、可新增页面（后续自增）

- 服务详情页：如 `/services/chip-repair`、`/services/industrial` 等
- 案例展示：如 `/cases` 列表 + 单页
- 博客/动态：沿用现有 `/blog` 结构，文案改为中文

## 六、技术实现要点

- `layouts/main.astro`：`lang="zh-CN"`，title/description 为「浙里修」相关中文。
- Header/Footer：导航与链接文案全中文；Logo 使用 `/images/logo.svg` 或纯文字「浙里修」。
- 各组件内：无界面可见英文（仅代码、域名等必要处保留）。
- 保留现有 Astro + React 组件结构、主题切换、响应式布局。
